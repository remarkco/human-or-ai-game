# Human or AI?

An interactive quiz game where players judge whether content was made by a human or generated by artificial intelligence. Built as a single-page, mobile-first web game with no dependencies and no build step.

## Run it

Open `index.html` in any browser — or serve the folder:

```sh
python3 -m http.server 8080
# then visit http://localhost:8080
```

Everything (SVG artwork, prose, voices, and music) is generated locally in `game.js`. No network, no API keys, no tracking.

## Game modes

- **Daily Challenge** — same 10 questions for everyone, chosen by a date-seeded shuffle. Completing it grants a +25 daily bonus.
- **Time Attack** — 60 seconds, +10 per correct answer, −5 per mistake, +15 bonus for every 5 correct in a row.
- **Specialist Challenge** — one category at a time (Images, Texts, Voices, Music).
- **Challenge a Friend** — a shareable link pins the same 10-question mix for both players.

## Content categories

| Category | Sample types |
|---|---|
| Images | Hand-drawn-style sketches vs mathematically "too-perfect" generated artwork |
| Texts | Posts, emails, poems, stories, reviews, recipes, diaries |
| Voices | Synthetic flat narration vs human dynamics (Web Audio speech-like synthesis) |
| Music | Quantized generative loops vs pieces with rubato and dynamics |

## Scoring

| Action | Points |
|---|---|
| Correct answer | +10 |
| Incorrect answer | −5 |
| 5 consecutive correct | +15 bonus |
| Completing 10 questions | +20 bonus |
| Completing the daily challenge | +25 bonus |

XP converts from points (80%), with 10 level titles from *Rookie* to *Master of Both Worlds*, plus 6 achievement badges.

## Persistence

Profile, XP, badges, and daily history are saved in `localStorage` (`hoai_profile`). In a production build this maps to a Supabase/PostgreSQL user record.

## Notes

- Audio samples are synthesized with the Web Audio API at runtime: "human" takes are hand-written note arrays with rubato and dynamics; "AI" takes are generated programmatically on quantized grids with uniform velocity — the detection explanations reference exactly these features.
- This prototype does not claim real AI-detection ability; every item is created and verified in this repository, mirroring the content-database design (verified source → correct answer → explanation) from the product spec.
